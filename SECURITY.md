# Security

This library converts text in memory. It reads no files (except the one you pass to the CLI), opens no network connections and has no runtime dependencies.

## Reporting a problem

Please report security problems privately to **support@kovapdf.com** (the contact in https://www.kovapdf.com/.well-known/security.txt). Do not open a public issue for a security problem. How KovaPDF handles reports: https://www.kovapdf.com/security

Please include the package version, how to reproduce the problem and what you expected. We aim to reply within a few working days.

## Supported versions

The latest released version on npm (`@kovapdf/krutidev-unicode`) and PyPI (`krutidev-unicode`).
