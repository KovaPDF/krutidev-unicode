# Changelog

## 1.0.0 (unreleased)

* First release: Kruti Dev 010 to Unicode and Unicode to Kruti Dev 010, taken from the KovaPDF website engine.
* JavaScript: ESM, CommonJS and TypeScript types, zero runtime dependencies, `krutidev-unicode` CLI.
* Python: pure Python port with the same functions (`to_unicode`, `to_kruti`, `convert_with_report`, `detect_encoding`, `is_kruti_font`, `split_into_parts`) and CLI.
* Shared test vectors (`test/vectors.json`) checked by both the JavaScript and the Python tests.
